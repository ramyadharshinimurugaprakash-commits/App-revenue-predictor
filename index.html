Input Features

🤖 Random Forest Regression

The model uses Random Forest Regression to predict monthly app revenue. The input features include app category, number of installs, transformed installs, rating, application size, days since update, application type, and price.

📊 Evaluation Metrics

R² Score: Measures how well the model explains the variation in revenue.

MAE: Measures the average absolute prediction error.

RMSE: Measures the square root of the average squared prediction error.

About the Project

App Revenue Prediction using Machine Learning

🎯 Project Objective

The objective of this project is to develop a machine learning system capable of predicting the monthly revenue of a mobile application based on its characteristics and performance.

📊 Dataset

The dataset contains information about mobile applications including category, installs, rating, size, update frequency, application type and price.

🤖 Machine Learning Model

Random Forest Regression is used to learn relationships between application features and monthly revenue. The trained model is then used to generate revenue predictions for new applications.
